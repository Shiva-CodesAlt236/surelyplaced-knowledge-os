# Information Request Deferral

Candidate requests written details (email, text, brochure) to review offline, often moving the conversation off-call.

**Why this matters:** Candidates frequently ask to be sent details via email when they feel overwhelmed, uncertain, or want to wrap up the call without isolating their core evaluation criteria.
**When to use this:** Any time a prospect says "email me the details", "send me info", or "mail me details so I can get back to you".
**What skill this builds:** Respectfully agreeing to send documentation while clarifying what specific topics the prospect wants to review so the live conversation remains productive.
**What happens next:** The advisor confirms the specific information needed and keeps the diagnostic dialog active.

## Lesson Objective

- Acknowledge information requests promptly without defensiveness
- Diagnose what specific program or commercial details the candidate wants to inspect
- Maintain collaborative dialogue live before ending the call
