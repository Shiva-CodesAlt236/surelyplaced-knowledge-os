# Objection Handling Checklist

This closes the module the way every checklist lesson in this academy closes its module: a practical check to run on any call, confirming an objection was actually handled well, not just gotten past.

## Lesson Objective

- Run the framework's first three steps in real time, during the objection itself
- Catch unconfirmed claims or slipped competitor criticism through honest self-review
- Tell a genuinely resolved objection apart from one that simply stopped being mentioned
