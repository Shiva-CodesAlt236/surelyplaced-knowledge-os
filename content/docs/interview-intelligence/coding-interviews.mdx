# Coding Interviews

## Purpose

A coding interview asks a candidate to write or reason through code live, under some form of time constraint, in front of an interviewer or a testing platform. This article covers what an advisor can offer around that experience without tutoring the candidate on programming itself.

## Scope

This article addresses the format and pressure candidates commonly describe in coding rounds, not programming instruction. It does not name a specific assessment length or platform as universal, since format varies considerably by employer, and it does not evaluate a candidate's coding ability.

## Core Content

What candidates often describe struggling with in this format isn't only the coding itself but narrating their thinking out loud while under time pressure — a skill distinct from coding ability that an advisor can reasonably discuss without technical expertise. Encouraging a candidate to practice thinking out loud, independent of the specific problems they'll face, is a legitimate and useful piece of coaching.

Anything touching the actual technical content — what topics to expect, how to solve a specific type of problem — belongs with an internal technical SME rather than the advisor's own judgment, consistent with this module's standing practice.

## Advisor Guidance

Coach the communication skill of narrating thinking out loud under time pressure, which doesn't require technical expertise, and route any question about actual coding content or difficulty to an internal SME.
