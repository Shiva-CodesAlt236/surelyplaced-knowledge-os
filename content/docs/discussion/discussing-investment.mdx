# Discussing Investment

> **Note on pricing:** This lesson teaches how to have the cost conversation honestly and well. It does not state a specific price, fee, payment structure, or discount anywhere, and it never will. Confirm current program cost and payment structure with the authoritative internal pricing resource before every investment conversation. Never quote a figure from memory.

By now the candidate understands the recommendation and the process. Cost is no longer an isolated number — it's tied to everything already discussed.

**Why this matters:** cost introduced before the value behind it lands as an isolated, unjustified number instead of a decision the candidate can actually evaluate.
**When to use this:** once the recommendation and the process are both genuinely understood — never earlier, and never avoided once they are.
**What skill this builds:** introducing cost directly, tied explicitly to value already discussed, and treating financial hesitation as real information.
**What happens next:** with cost on the table honestly, the discussion call moves toward its close and confirming the candidate's real next steps.

## Lesson Objective

- Introduce cost directly, once earlier stages have earned the right to raise it
- Tie the number explicitly to value already discussed — never present it in isolation
- Treat financial hesitation as real information, not an obstacle to push past

## Coaching Notes

<CoachingNotes title="Coaching Notes">
Let the silence after stating cost actually sit. Don't fill it by softening the number before Akash has said anything. He needs a moment to process, not a reflex response from you.
</CoachingNotes>

<CoachingNotes title="Why This Worked">
Separating "is this a fair number" from "is now the right time financially" matters because they sound identical in the first sentence but need completely different responses. Answering the wrong one wastes trust and doesn't resolve anything.
</CoachingNotes>
