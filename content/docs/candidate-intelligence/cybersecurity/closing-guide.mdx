# Closing Guide

> No specific price, guarantee, or placement outcome is stated in this guide.

## Purpose

This guide applies the existing Closing module to `ROLE-SEC`, completing this collection's four-stage advisor playbook.

## Scope

This guide covers closing-call approach for cybersecurity candidates broadly, building on [Decision to Enrollment](/docs/closing/decision-to-enrollment), [Asking for the Commitment](/docs/closing/asking-for-the-commitment), and [Handling Final Hesitation](/docs/closing/handling-final-hesitation).

## Core Content

Before moving to a decision, consistent with [Decision to Enrollment](/docs/closing/decision-to-enrollment), confirm specifically that any trust or credibility concern raised earlier — a pattern this role family surfaces more explicitly than most, per [Objection Guide](/docs/candidate-intelligence/cybersecurity/objection-guide) — was genuinely resolved, not just set aside.

Ask for the commitment directly, consistent with [Asking for the Commitment](/docs/closing/asking-for-the-commitment), without leaning on visa timeline as pressure — the specific visa category's timeline is a real factor being weighed, not a closing lever.

If hesitation appears, apply [Handling Final Hesitation](/docs/closing/handling-final-hesitation), watching for genuine financial vulnerability per [Pricing Red Flags](/docs/pricing/pricing-red-flags), particularly relevant for earlier-career candidates or those transitioning from adjacent IT roles into a dedicated security pattern for the first time.

Handle payment and agreement consistent with [Payment and Agreement Process](/docs/closing/payment-and-agreement-process), watching for a financial co-decision-maker per [Financial Decision-Makers](/docs/pricing/financial-decision-makers) where career stage suggests it may be relevant.

## Cross-Module Alignment

This guide applies [Decision to Enrollment](/docs/closing/decision-to-enrollment), [Asking for the Commitment](/docs/closing/asking-for-the-commitment), [Handling Final Hesitation](/docs/closing/handling-final-hesitation), and [Financial Decision-Makers](/docs/pricing/financial-decision-makers), shaped by this collection's earlier findings.

## Advisor Guidance

Confirm trust and credibility concerns were genuinely resolved before closing, never lean on visa timeline as pressure, and stay alert to financial vulnerability among candidates newer to a dedicated security career path.
