# Role Classification

> This article defines a taxonomy — a fixed list of role categories and codes. It does not describe any actual candidate, and no code below is attached to real or illustrative-but-realistic candidate data.

## Purpose

`role_category` in [Profile Schema](/docs/candidate-intelligence/PROFILE_SCHEMA) requires a single, defined code rather than freeform text. This article is the authoritative list of those codes, so every profile classifies a candidate's professional role the same way.

## Scope

This taxonomy classifies a candidate's professional role for the purpose of routing an advisor to the correct existing playbook content — it is not a technical skills assessment, a hiring evaluation, or a substitute for genuine discovery conversation with the candidate.

## Standard Structure

Each role category below maps one-to-one to an existing article in the Industry Playbooks module, so classifying a candidate immediately connects a profile to the relevant sales guidance already documented there.

## Required Fields

The defined role categories, each mapped to its corresponding playbook:

| Code | Category | Maps To |
|---|---|---|
| `ROLE-SWE` | Software Engineering | [Software Engineering Playbook](/docs/industry-playbooks/software-engineering-playbook) |
| `ROLE-DATA` | Data & AI | [Data and AI Playbook](/docs/industry-playbooks/data-and-ai-playbook) |
| `ROLE-SEC` | Cybersecurity | [Cybersecurity Playbook](/docs/industry-playbooks/cybersecurity-playbook) |
| `ROLE-CLOUD` | Cloud & DevOps | [Cloud DevOps Playbook](/docs/industry-playbooks/cloud-devops-playbook) |
| `ROLE-QA` | QA & Testing | [QA Testing Playbook](/docs/industry-playbooks/qa-testing-playbook) |
| `ROLE-HEALTH` | Healthcare | [Healthcare Playbook](/docs/industry-playbooks/healthcare-playbook) |
| `ROLE-SUPPLY` | Supply Chain | [Supply Chain Playbook](/docs/industry-playbooks/supply-chain-playbook) |
| `ROLE-BA` | Business Analyst | [Business Analyst Playbook](/docs/industry-playbooks/business-analyst-playbook) |
| `ROLE-PM` | Project Manager | [Project Manager Playbook](/docs/industry-playbooks/project-manager-playbook) |
| `ROLE-PENDING` | Category Pending | No existing playbook matches — see [Industry Discovery Framework](/docs/industry-playbooks/industry-discovery-framework) for the general approach until a specific playbook exists |

## Relationships with Other Modules

This taxonomy is a direct index into Industry Playbooks — it doesn't introduce any role definition or evaluation criteria of its own. [Industry Mapping](/docs/candidate-intelligence/INDUSTRY_MAPPING) uses these same codes to route profile data to playbook content, and [Technology Mapping](/docs/candidate-intelligence/TECHNOLOGY_MAPPING) records technical context within whichever role category applies.

## Author Guidelines

Assign the code that best matches a candidate's actual professional background, based on genuine discovery conversation — never assign a code based on assumption alone. Use `ROLE-PENDING` honestly when a candidate's background doesn't clearly match any existing category, rather than forcing an inaccurate fit for the sake of completing the field.

## Reviewer Checklist

- [ ] Is the assigned role code one of the ten defined codes above, not a freeform or invented category?
- [ ] Does the assigned code genuinely reflect the candidate's actual background, based on real discovery rather than assumption?
- [ ] Is `ROLE-PENDING` used honestly where no category fits, rather than a forced approximation?
