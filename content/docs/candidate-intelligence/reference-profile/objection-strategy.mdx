# Reference Profile: Objection Strategy

> This article is part of the Gold Standard reference profile — an illustrative archetype, never a real person. This article anticipates likely objection patterns; it does not describe a real conversation.

## Purpose

This article shows how a completed profile anticipates likely objections for a specific archetype and routes each to the correct existing guidance, rather than restating objection-handling technique from scratch.

## Layer 1 — Candidate Identity

Unchanged from earlier in this profile: an early-career software engineer on F-1 OPT.

## Layer 2 — Sales Intelligence

Given the `PERSONA-SKEPTIC` and OPT-timeline patterns from [Candidate Mindset](/docs/candidate-intelligence/reference-profile/candidate-mindset), three objection types are most likely for this archetype.

## Layer 3 — Advisor Playbook

**A comparison objection** is likely — this archetype is prone to researching alternatives before committing, consistent with the comparison-objection variant in [Handling Price Objections](/docs/pricing/handling-price-objections). If the candidate mentions an alternative consultancy specifically, apply [Already Working With a Consultancy](/docs/objections/already-working-with-a-consultancy) and [Consultancy Comparison Case Study](/docs/sales-coaching/consultancy-comparison-case-study) — describe Surely Placed's own approach honestly rather than criticizing the alternative.

**A value-uncertainty objection** is likely, often expressed as a direct request for a specific ROI figure — apply [ROI Conversations](/docs/pricing/roi-conversations) precisely, redirecting to qualitative value rather than citing a number.

**A timeline-driven affordability or urgency objection** is possible, given the bounded OPT window — apply [Need Time to Think](/docs/objections/need-time-to-think) if the candidate wants space to decide despite time pressure, respecting that request rather than treating the OPT deadline as license to rush them.

## Cross-Module Alignment

Every objection type and response in this article routes directly to existing guidance in Objections, Pricing, and Sales Coaching — this reference profile introduces no new objection-handling technique.
