# Reference Profile: Overview

> **This is not a real person, and it is not based on any individual candidate.** This reference profile is the single canonical, illustrative implementation of the framework defined in [Profile Schema](/docs/candidate-intelligence/PROFILE_SCHEMA) — it demonstrates structure, not a real case. This is the only reference profile in this repository; no additional profiles are created in this sprint.

## Purpose

[Profile Template](/docs/candidate-intelligence/PROFILE_TEMPLATE) is a blank document. This reference profile is what a completed one looks like, filled in with a fully illustrative, archetype-level candidate rather than real data, so future profile-writers have a working example to model rather than only an abstract schema.

## Layer 1 — Candidate Identity

The illustrative candidate this reference profile describes, referred to throughout as "the reference candidate" or by the placeholder name "Riley," represents the archetype most commonly seen at Surely Placed: an early-career software engineer on F-1 OPT status.

Using the codes defined in the Candidate Intelligence Framework: `role_category: "ROLE-SWE"` (see [Role Classification](/docs/candidate-intelligence/ROLE_CLASSIFICATION)), `visa_category: "VISA-F1OPT"` (see [Visa Mapping](/docs/candidate-intelligence/VISA_MAPPING)), career stage: early career (a small number of years or less of professional experience, sometimes the candidate's first role since graduating).

## Layer 2 — Sales Intelligence

This layer — the candidate's likely mindset, buying signals, and risk signals — is covered in depth across [Candidate Mindset](/docs/candidate-intelligence/reference-profile/candidate-mindset), [Buying Signals](/docs/candidate-intelligence/reference-profile/buying-signals), and [Risk Signals](/docs/candidate-intelligence/reference-profile/risk-signals), each built from patterns already documented in Pricing, Objections, and the Visa and Industry Playbooks.

## Layer 3 — Advisor Playbook

This layer — stage-by-stage advisor strategy for this archetype — spans [Discovery Strategy](/docs/candidate-intelligence/reference-profile/discovery-strategy) through [Closing Strategy](/docs/candidate-intelligence/reference-profile/closing-strategy), plus [Interview Support](/docs/candidate-intelligence/reference-profile/interview-support) and [Advisor Coaching Notes](/docs/candidate-intelligence/reference-profile/advisor-coaching-notes).

## Cross-Module Alignment

This reference profile is built entirely from patterns already documented elsewhere: [F1/OPT Playbook](/docs/visa-playbooks/f1-opt-playbook) and [Software Engineering Playbook](/docs/industry-playbooks/software-engineering-playbook) for the archetype's foundation, [Composite Case Study: OPT Software Engineer](/docs/sales-coaching/composite-case-study-opt-software-engineer) for a worked conversational example of this same archetype, and the full Discovery through Sales Constitution modules for stage-specific guidance.
