# Reference Profile: Checklist

> This article closes the Gold Standard reference profile — an illustrative archetype, never a real person. Use this checklist both to verify this reference profile itself and as a model for checking any future actual profile built from it.

## Purpose

[Profile QA Guidelines](/docs/candidate-intelligence/PROFILE_QA_GUIDELINES) defines how a future profile should be checked in general. This checklist applies that same discipline specifically to the thirteen articles that make up this reference profile, and doubles as a template a future profile-writer can adapt.

## Layer 1 — Candidate Identity

- [ ] Does [Overview](/docs/candidate-intelligence/reference-profile/overview) clearly state this is not a real person and is the sole canonical reference implementation?
- [ ] Do [Career Background](/docs/candidate-intelligence/reference-profile/career-background) and [Technology Profile](/docs/candidate-intelligence/reference-profile/technology-profile) stay generic, with no invented employer, institution, date, or specific technical claim?

## Layer 2 — Sales Intelligence

- [ ] Does [Candidate Mindset](/docs/candidate-intelligence/reference-profile/candidate-mindset) ground every persona signal in an existing module rather than inventing a new psychological claim?
- [ ] Do [Buying Signals](/docs/candidate-intelligence/reference-profile/buying-signals) and [Risk Signals](/docs/candidate-intelligence/reference-profile/risk-signals) draw every signal from an existing "Buying Signals" or "Risk Signals" section elsewhere in the Knowledge OS?

## Layer 3 — Advisor Playbook

- [ ] Do [Discovery Strategy](/docs/candidate-intelligence/reference-profile/discovery-strategy) through [Closing Strategy](/docs/candidate-intelligence/reference-profile/closing-strategy) apply existing stage-specific modules directly, without introducing new technique?
- [ ] Does [Interview Support](/docs/candidate-intelligence/reference-profile/interview-support) correctly mark undocumented program specifics as Operational Policy Pending rather than inventing a curriculum?
- [ ] Does [Advisor Coaching Notes](/docs/candidate-intelligence/reference-profile/advisor-coaching-notes) clearly mark its example coaching note as hypothetical and illustrative only?

## Cross-Module Alignment

- [ ] Does every article in this reference profile cross-reference at least one existing module (Discovery, Discussion, Closing, Objections, Visa Playbooks, Industry Playbooks, Pricing, Sales Operations, Sales Coaching, Sales Constitution, or the Candidate Intelligence Framework)?
- [ ] Does the profile avoid stating any placement outcome, salary figure, guarantee, company policy, or immigration advice anywhere across all fourteen articles?

## Key Takeaways

This checklist confirms the reference profile follows the Layered Model consistently across all fourteen articles, grounds every Layer 2 and Layer 3 claim in an existing module rather than inventing new fact or technique, and states no placement outcome, salary, guarantee, or policy anywhere. It also serves as a working template for checking any future actual profile built from this one.
