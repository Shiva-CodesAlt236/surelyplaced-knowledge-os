# Reference Profile: Advisor Coaching Notes

> This article is part of the Gold Standard reference profile — an illustrative archetype, never a real person or real advisor. Every coaching signal below is hypothetical, demonstrating format only.

## Purpose

[Coaching Signals](/docs/candidate-intelligence/COACHING_SIGNALS) defines the codes a profile uses to flag reviewable moments. This article shows what that field looks like when populated for a conversation with this archetype, closing out this profile's Layer 3 content with the same coaching discipline applied throughout Sales Coaching.

## Layer 1 — Candidate Identity

Not the primary focus of this article — coaching notes concern advisor performance, not candidate identity.

## Layer 2 — Sales Intelligence

Not the primary focus of this article — see [Candidate Mindset](/docs/candidate-intelligence/reference-profile/candidate-mindset) for the sales-intelligence layer these notes would be reviewed against.

## Layer 3 — Advisor Playbook

Given the patterns established throughout this profile, coaching review for conversations with this archetype should pay particular attention to a few recurring risk areas. Whether the advisor correctly distinguished the skepticism-first `PERSONA-SKEPTIC` pattern from genuine disengagement, consistent with the reading discipline in [Reading a Sales Conversation](/docs/sales-coaching/reading-a-sales-conversation) — treating detailed questioning as engagement rather than resistance is a common point of miscalibration with this archetype. Whether the advisor held the ROI Conversations discipline under a direct request for a figure, which this archetype is statistically likely to make. Whether OPT timeline urgency was ever used, even subtly, as a closing pressure tactic rather than being treated as a factor the candidate is honestly weighing.

**Illustrative Only** — a hypothetical coaching note demonstrating format: `coaching_notes: ["COACH-STRONG-MOMENT — held ROI Conversations discipline calmly when candidate directly asked for a specific return figure"]`. This is a hypothetical entry, not a record of a real conversation.
