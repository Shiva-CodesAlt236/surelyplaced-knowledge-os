# Closing Guide

> This guide names no figure, discount, or promised outcome anywhere — closing technique only.

## Purpose

This guide applies the existing Closing module to `ROLE-CLOUD`, completing this collection's four-stage advisor playbook.

## Scope

This guide covers closing-call approach for Cloud & DevOps candidates broadly, building on [Decision to Enrollment](/docs/closing/decision-to-enrollment) and [Asking for the Commitment](/docs/closing/asking-for-the-commitment).

## Core Content

Before moving to a decision, consistent with [Decision to Enrollment](/docs/closing/decision-to-enrollment), confirm explicitly that any scope-and-fit concern surfaced earlier — the most common underlying hesitation for this population, per [Objection Guide](/docs/candidate-intelligence/cloud-devops/objection-guide) — has actually been resolved and not just quietly set aside.

Ask for the commitment directly and efficiently, consistent with [Asking for the Commitment](/docs/closing/asking-for-the-commitment) — a drawn-out close tends to work against this population's preference for directness rather than build additional trust.

Handle payment and agreement consistent with [Payment and Agreement Process](/docs/closing/payment-and-agreement-process). Where the candidate's working pattern is earlier-career or newly transitioned into this field, per [Infrastructure Engineer](/docs/candidate-intelligence/cloud-devops/infrastructure-engineer), stay alert to financial vulnerability per [Pricing Red Flags](/docs/pricing/pricing-red-flags) the same way any other role family would warrant.

## Cross-Module Alignment

This guide applies [Decision to Enrollment](/docs/closing/decision-to-enrollment), [Asking for the Commitment](/docs/closing/asking-for-the-commitment), and [Payment and Agreement Process](/docs/closing/payment-and-agreement-process), shaped by this collection's scope-and-fit and directness findings.

## Advisor Guidance

Confirm scope-and-fit concerns were genuinely resolved before closing, keep the close itself efficient and direct, and stay alert to financial vulnerability among candidates newer to this specific specialization.
