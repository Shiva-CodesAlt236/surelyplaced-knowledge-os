# Cloud & DevOps Role Collection — Overview

> This is the fourth complete Role Collection built on the Candidate Intelligence Framework, following the Software Engineering, Data & AI, and Cybersecurity collections.

## Purpose

This article introduces the Cloud & DevOps Role Collection, mapped to `ROLE-CLOUD` in [Role Classification](/docs/candidate-intelligence/ROLE_CLASSIFICATION) and to the [Cloud & DevOps Playbook](/docs/industry-playbooks/cloud-devops-playbook). It orients an advisor to the four working patterns this collection documents and how this collection relates to the collections that came before it.

## Scope

This collection covers candidates whose work centers on infrastructure, deployment pipelines, operational reliability, and cloud platform design — distinct from application-level software development, and distinct from the security-specific slice of cloud work already documented in [Cloud Security Engineer](/docs/candidate-intelligence/cybersecurity/cloud-security-engineer) within the Cybersecurity collection. Where those two overlap in a real candidate's background, an advisor should treat the candidate's stated primary focus as the guide to which collection's framing fits best, rather than trying to categorize the person definitively.

## Core Content

This collection documents four working patterns common within `ROLE-CLOUD`: [Infrastructure Engineer](/docs/candidate-intelligence/cloud-devops/infrastructure-engineer), [Site Reliability Engineer](/docs/candidate-intelligence/cloud-devops/site-reliability-engineer), [DevOps / Platform Engineer](/docs/candidate-intelligence/cloud-devops/devops-platform-engineer), and [Cloud Architect](/docs/candidate-intelligence/cloud-devops/cloud-architect). It then covers the ecosystem of representative tools at [Technology Ecosystem](/docs/candidate-intelligence/cloud-devops/technology-ecosystem), this role family's sales intelligence at [Candidate Behaviour](/docs/candidate-intelligence/cloud-devops/candidate-behaviour) and [Buying Patterns](/docs/candidate-intelligence/cloud-devops/buying-patterns), a four-stage advisor playbook, coaching priorities, and a closing checklist.

## Cross-Module Alignment

This collection builds directly on the [Candidate Intelligence Framework](/docs/candidate-intelligence/README), the [Gold Standard Reference Profile](/docs/candidate-intelligence/reference-profile/overview), the [Cloud & DevOps Playbook](/docs/industry-playbooks/cloud-devops-playbook), and the structural pattern established by the [Software Engineering](/docs/candidate-intelligence/software-engineering/overview), [Data & AI](/docs/candidate-intelligence/data-and-ai/overview), and [Cybersecurity](/docs/candidate-intelligence/cybersecurity/overview) collections.

## Advisor Guidance

Use this overview as the entry point before moving to a specific working-pattern article. When a candidate's background touches both general cloud infrastructure and security, cross-check this collection against the Cybersecurity collection's [Cloud Security Engineer](/docs/candidate-intelligence/cybersecurity/cloud-security-engineer) rather than assuming one framing covers everything.
