# Objection Guide

> No real conversation is described anywhere in this guide, and it names no price, discount, guaranteed result, or platform comparison.

## Purpose

This guide applies the existing Objection Handling module to the SAP role family, continuing this collection's four-stage advisor playbook.

## Scope

This guide covers objection-handling approach for SAP candidates broadly, building on [Trust and Credibility](/docs/objections/trust-and-credibility) and [Need Time to Think](/docs/objections/need-time-to-think).

## Core Content

Per [Candidate Behaviour](/docs/candidate-intelligence/sap/candidate-behaviour), an objection that sounds like [Trust and Credibility](/docs/objections/trust-and-credibility) sometimes actually traces back to a sequencing inconsistency earlier in the conversation — check for that before responding as though the concern is about the advisor's general credibility.

[Need Time to Think](/docs/objections/need-time-to-think) may reflect this population's genuine, structured evaluation habit rather than reluctance — this population is accustomed to phase-gated decision-making professionally, and a request for time to think through the sequence deliberately should be respected rather than treated as a soft decline.

Watch for hesitation that traces back to an unclear or inconsistently explained step in the process, per [Buying Patterns](/docs/candidate-intelligence/sap/buying-patterns) — naming and correcting the inconsistency directly usually resolves it faster than restating the opportunity's other merits.

## Cross-Module Alignment

This guide applies [Trust and Credibility](/docs/objections/trust-and-credibility) and [Need Time to Think](/docs/objections/need-time-to-think), shaped by this collection's process-rigor findings.

## Advisor Guidance

Check for a sequencing inconsistency before treating an objection as a general trust concern, respect a request for time to think as this population's structured evaluation habit rather than reluctance, and correct any process inconsistency explicitly.
