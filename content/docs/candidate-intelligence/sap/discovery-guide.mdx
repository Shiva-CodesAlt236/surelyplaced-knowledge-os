# Discovery Guide

## Purpose

This guide applies the existing Discovery module to the SAP role family, opening this collection's four-stage advisor playbook.

## Scope

This guide covers discovery-call approach for SAP candidates broadly, building on [Opening the Discovery Call](/docs/discovery/opening-the-discovery-call) and [Understanding Candidate Goals](/docs/discovery/understanding-candidate-goals).

## Core Content

Introduce the overall shape of the process early and in sequence, per [Candidate Behaviour](/docs/candidate-intelligence/sap/candidate-behaviour) — this population evaluates any process through a structured, phase-literate lens, and hearing the sequence up front tends to build confidence faster than describing it piecemeal as questions come up.

Consistent with [Understanding Candidate Goals](/docs/discovery/understanding-candidate-goals), ask which functional module, technical focus, or program-level scope the candidate specializes in, since this collection's four working patterns span a real range from module-specific to program-wide responsibility.

If a step in the conversation departs from what was described earlier, name that departure directly rather than letting it pass, per [Buying Patterns](/docs/candidate-intelligence/sap/buying-patterns) — this population notices sequencing inconsistencies quickly, and addressing them directly protects trust.

## Cross-Module Alignment

This guide applies [Opening the Discovery Call](/docs/discovery/opening-the-discovery-call) and [Understanding Candidate Goals](/docs/discovery/understanding-candidate-goals), shaped by this collection's process-rigor findings.

## Advisor Guidance

Introduce the process sequence early and clearly, confirm the candidate's specific working pattern within this collection's range, and name any departure from the stated sequence directly rather than letting it pass unaddressed.
