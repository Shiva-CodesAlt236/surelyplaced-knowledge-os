# Presentation Guide

## Purpose

This guide applies the existing Discussion module to `ROLE-PM`, continuing this collection's four-stage advisor playbook.

## Scope

This guide covers presentation-call approach for Project Management candidates broadly, building on [Presenting Surely Placed](/docs/discussion/presenting-surely-placed) and [Explaining the Process](/docs/discussion/explaining-the-process).

## Core Content

Present the recommendation the way this population would present a project to a stakeholder, per [Candidate Behaviour](/docs/candidate-intelligence/project-management/candidate-behaviour) — a clear sequence of what happens next, in what order, with honest visibility into anything uncertain. Avoid rounding up or smoothing over open questions, since this population is trained to notice exactly that kind of gap.

When explaining the process per [Explaining the Process](/docs/discussion/explaining-the-process), name dependencies and risks explicitly rather than only the happy path — this mirrors the standard this population holds their own project communication to, and meeting it directly builds credibility fast.

Never introduce artificial urgency at this stage. Per [Buying Patterns](/docs/candidate-intelligence/project-management/buying-patterns), this population is unusually skilled at recognizing manufactured pressure, and it tends to cost trust rather than accelerate a decision.

## Cross-Module Alignment

This guide applies [Presenting Surely Placed](/docs/discussion/presenting-surely-placed) and [Explaining the Process](/docs/discussion/explaining-the-process), shaped by this collection's plan-and-risk-transparency findings.

## Advisor Guidance

Present next steps as a clear, honest sequence, name dependencies and risks rather than only the happy path, and never introduce artificial urgency with this population.

## Key Takeaways

Presenting to this role family works best as a clear, honest sequence of next steps that names risk and dependency directly, since this population is unusually well-equipped to notice — and penalize — a smoothed-over or artificially urgent pitch.
