# Technical Project Coordinator

## Purpose

This article describes the Technical Project Coordinator working pattern within `ROLE-PM` — candidates who support a project's schedule, documentation, and logistics without yet owning delivery outcomes themselves.

## Scope

This article covers what typically distinguishes an early-career, support-oriented candidate from the other three working patterns in this collection, for sales-conversation purposes only.

## Core Content

Candidates in this pattern describe their work in terms of tracking tasks, maintaining schedules, organizing meetings, and keeping documentation current for a project someone more senior ultimately owns. Many are early in a project management career path, sometimes having moved into this pattern from an adjacent operational or administrative role rather than starting in project delivery directly.

What separates this pattern most clearly from [IT Project Manager](/docs/candidate-intelligence/project-management/it-project-manager) is ownership: a coordinator supports the plan, while a project manager is accountable for it. Candidates in this pattern are often actively working toward that next step, which makes career trajectory a genuinely relevant discovery topic rather than an afterthought.

## Cross-Module Alignment

This pattern represents the earliest-career end of the spectrum the [Project Manager Playbook](/docs/industry-playbooks/project-manager-playbook) describes only in general terms, giving it a concrete entry point comparable to [Manual QA Tester](/docs/candidate-intelligence/qa-testing/manual-qa-tester) in the QA Testing collection.

## Advisor Guidance

Ask directly about career trajectory and whether the candidate is actively working toward full project ownership — for this pattern, that ambition is usually central to what they're looking for next, not incidental.
