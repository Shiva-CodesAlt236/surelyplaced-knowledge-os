# IT Project Manager

## Purpose

This article describes the IT Project Manager working pattern within `ROLE-PM` — candidates who own the plan, timeline, and risk for a single technical project or workstream from start to finish.

## Scope

This article covers what typically distinguishes a candidate who fully owns project delivery from the other three working patterns in this collection, for sales-conversation purposes only.

## Core Content

Candidates in this pattern are accountable for outcomes they don't fully control themselves — a project's success depends on other people's work, which shapes a distinctive professional habit of building realistic plans, surfacing risk honestly, and managing stakeholder expectations rather than promising outcomes outright. Many candidates in this pattern describe a specific project as a defining professional example, usually one where a real risk or setback was managed transparently rather than one that went perfectly.

This pattern sits at the center of the collection's spectrum, more senior than [Technical Project Coordinator](/docs/candidate-intelligence/project-management/technical-project-coordinator) but typically managing a single workstream rather than the multi-project portfolio a [Program Manager](/docs/candidate-intelligence/project-management/program-manager) would oversee.

## Cross-Module Alignment

This pattern gives specific shape to the core population the [Project Manager Playbook](/docs/industry-playbooks/project-manager-playbook) describes generally, anchoring its plan-and-risk-transparency theme in a concrete working pattern.

## Advisor Guidance

Ask for a specific example of a project where something went wrong and how it was handled — this population tends to trust a conversation more once it's clear the advisor values honest risk discussion over a polished success story.

IT Project Managers own delivery of a single project or workstream and are accountable for outcomes they don't fully control, which shapes a professional habit of realistic planning and honest risk communication that a conversation with this pattern should mirror directly.
